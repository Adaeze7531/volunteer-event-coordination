# Volunteer Event Coordination

## Project Overview

A portfolio case study demonstrating my experience supporting virtual volunteer event planning, communication, coordination, and follow-up.

I supported key administrative activities throughout the event lifecycle, from the initial event announcement and preparation through event-day coordination and post-event communication.

## My Role

My responsibilities included:

- Announcing the event date to the organization
- Creating the event poster
- Creating and distributing the event newsletter
- Developing the event agenda and presentation
- Planning activities such as games and prizes
- Communicating with invited speakers
- Coordinating with the event host
- Sending reminder communications before the event
- Supporting the virtual event on Google Meet
- Sending a post-event thank-you email
- Preparing an event update for Board members who were unable to attend

## Event Coordination Process

The event coordination workflow followed these stages:

1. Event date announcement
2. Event planning and agenda development
3. Event materials preparation
4. Event promotion and communication
5. Speaker and host coordination
6. Reminder communications
7. Virtual event coordination
8. Post-event follow-up
9. Board update

## Communication

Communication was organized according to the audience and stage of the event:

- Initial event announcement
- Newsletter promotion
- Speaker and host communication
- Reminder emails
- Post-event thank-you message
- Board update
